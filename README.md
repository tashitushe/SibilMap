# SibilMap

A personal map-poster studio. Search any place, pick a palette, tune the layers and typography, and export a print-ready PNG.

Inspired by Terraink.

**Live demo:** [farnoud.net/map](https://farnoud.net/map)

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes
- Map data © OpenStreetMap contributors, vector tiles via OpenFreeMap, search via Nominatim (respect its usage policy).
- The preview is a fixed 1000 px-wide logical poster scaled to fit; export re-renders the same view at 2000/3000/4500 px.
